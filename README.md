A one-line autocorrect fail for the make.fun bounty
[Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154).

The entry is a text message home where autocorrect quietly turned
"dinner" into "divorce" — funny on first read, no explanation needed.

## How to run

```bash
python3 main.py
```

This writes the single entry line to `/output/entry.txt` (creating
`/output` if needed), validates that it is one line of 1–199 characters,
and prints it.

## Entry

> Hey honey, I'm on my way home — what do you want for divorce tonight? I was thinking Italian.
